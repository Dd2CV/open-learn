## 学习路径建议

```
入门（0-3个月）
  ├── 网络/系统/安全基础
  └── TryHackMe Pre-Security、Linux Journey

进阶（3-6个月）
  ├── Web安全（OWASP Top 10）
  ├── 渗透测试基础（Kali Linux、Burp Suite）
  └── OSCP 备考

高级（6个月+）
  ├── 内网渗透与域安全
  ├── 代码审计与漏洞挖掘
  └── 云安全/AI安全/零信任架构
```

## 使用方式

- 按模块顺序学习，每个模块标注了优先级
- 结合实战靶场练习，理论占20%，实操占80%
- 遇到问题随时可以提问，我会辅助你进行漏洞挖掘
